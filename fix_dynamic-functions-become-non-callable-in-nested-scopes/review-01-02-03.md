# Review — tickets 01, 02, 03

Three reviewers over `git diff $(git merge-base develop HEAD)`: the Standards
and Spec axes of the `code-review` skill, and a performance-only third.

Gates at the time of the review: `cargo fmt --all -- --check`,
`cargo clippy --workspace --all-features --all-targets` (no warnings),
`cargo test --workspace --all-features --no-fail-fast`, `pnpm format:check`,
`pnpm lint:check`, and `pnpm test` (97 of 97 tasks) all pass. The native
binding was rebuilt before the JavaScript suite ran.

## Corrected in the reviewers' findings

- Standards said `CounterMode::ThreadLocal` survives in two places. Both use
  `CounterMode::Local`, which is per-instance and reset on construction, so
  neither carries the defect.
- Standards flagged the two hash parameters as transposable. They are `u128`
  and `Option<u128>`, so swapping them does not compile.
- Spec said ticket 03's plan item for the source-file lookup was left stale. It
  was implemented differently on purpose: a lookup by file name would silently
  turn the feature off, because the test harness registers the source under its
  own file name and not the one a test sets. A containment check closes the
  hazard instead.

## Declined

- **The primary injection slot for a hoisted call.** Spec pushed back that the
  two tests pinning it use a combination production never produces. Fair, but
  `register_styles` is a library API whose stated behaviour is to inject in
  front of both shapes because only one survives. Narrowing that to save one
  `ModuleItem` clone per rule is a poor trade.
- **One avoidable copy of the module text in the diagnostics crate.** Needs the
  memo to hold a shared string, which is trait-level churn for one copy per
  file.
- **Quoting a module that failed to parse.** Tried, and two tests refused it:
  a span whose offsets belong to a text that did not parse would be labelled
  with the real file name and a line that is not that file's line. "Location
  unknown" is the honest answer.

## Open, and not for this branch

- `CounterMode::ThreadLocal` now has no production caller. Left in place: it is
  a public variant with its own tests, not an orphan of this change.
- Two commits spell the scope `rs-compiler` where the conventions ask for
  `stylexswc/rs-compiler`. Amending needs written approval.
- The dev fixture bench series will shift, because the debug naming path went
  from cold to hot. 15 entries of `benchmark/fixtures.v1.json` run with `dev`
  on, and that is a separately watched series. The paired bench cannot run on
  this platform, so the increase needs attributing in continuous integration.
- The largest remaining win on that path is the copy of a namespace's whole
  property map made to prepend one key. It needs the slot reserved where the
  compiled styles are built, since the name has to come first.
