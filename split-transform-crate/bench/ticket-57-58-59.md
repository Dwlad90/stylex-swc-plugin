# Tickets 57, 58, 59 — what moved, and what a reader must not compare

**Read this before comparing any number against
[`ticket-17.md`](./ticket-17.md).** That record is the reference point for the
criterion series. This change closes part of it: 195 measurements gained a
check, nine of them were timing a refusal and now time a parse, and three
changed what they build. A number from `ticket-17.md` and a number from here
describe different work wherever this file says so.

| Item | Value |

## The defect the checks found

Writing the counts for `performance_bench.rs` needed an answer to compare
against, and the answers disagreed with themselves. The same merge read 2 class
names or 4 depending on what had been asked for earlier, and a style asked for
on its own after a merge read as an empty class name.

The memo was one flat map. The reference gives every entry its own child map
and descends into it, so a style cached behind another is found behind it and
never at the root. That matters because a cached chunk holds only the
properties the styles after it had not already defined: it is cut for one merge
and true of no other. One flat map answered it to every merge.

Checked against the reference implementation, which is order-independent in
every case tried. Four tests pin the fix, and two more pin a second divergence
found beside it: an inline property whose value is undefined is invisible
upstream, and this port let it take the property from a style that declared one.

### What the fix costs

Nothing on the path the compiler walks, and the styleq bench cannot see it
either way, because it builds its `Styleq` once outside `b.iter` and therefore
only ever measures cache hits. The compiler builds one per call site and
measures only misses. The two figures worth knowing:

- **Hit:** two more atomic refcount operations per style, for descending the
  chain. About 20 of them on the largest merge in the bench, against 1.5 µs.
- **Miss:** the child node is built on first descent rather than with the
  entry, so a style nothing is cached behind costs no allocation at all. That
  is every style the compiler merges.

## How to compare against this

Do not, except within one of the tables above. Re-baseline the workspace on a
quiet machine, record it beside `ticket-17.md`, and compare against that.
